常见问题

浏览器打不开连接页面？

① 确认菜单栏图标里服务已「开始服务」；② 确认浏览器设备与 Mac 在同一局域网；③ 地址栏输入 https://你的Mac名称:9443（注意是 https）；④ 首次连接会提示「证书不受信任」——这是预期行为（证书由本机自动生成，纯局域网使用），在 Safari 点「显示详细信息 → 访问此网站」，Chrome 点「高级 → 继续前往」。

画面是黑的 / 看不到屏幕？

需要「屏幕录制」权限：菜单栏图标 → 设置 → 权限向导，按提示在「系统设置 → 隐私与安全性 → 屏幕录制」中允许 CuteRemote，应用会自动重启生效。

浏览器里无法控制鼠标键盘？

远程输入需要「辅助功能」权限：菜单栏图标 → 设置 → 权限向导，在「系统设置 → 隐私与安全性 → 辅助功能」中允许 CuteRemote。不授予该权限不影响观看。

忘记访问密码？

在 Mac 端：菜单栏图标 → 设置 → 密码区域，清除后重新设置即可。

多台设备能同时连接吗？

可以。默认允许 3 台设备同时观看，最大可在设置中调整为 10。满员后新设备会被拒绝，需等现有设备断开。

数据会上传到云端吗？

不会。画面与输入全程在你的局域网内点对点加密传输，CuteRemote 没有云端服务器、不收集任何数据。详见隐私政策。

FAQ

The browser can't open the connection page?

1) Make sure the service is started from the menu bar icon; 2) make sure the browser device is on the same local network as the Mac; 3) type https://your-mac-name:9443 (https, not http); 4) on first connect the browser warns about an untrusted certificate — this is expected: the certificate is generated locally on your Mac for LAN use. In Safari choose "Show Details → Visit Website"; in Chrome choose "Advanced → Proceed".

Black screen / no video?

Screen Recording permission is required: menu bar icon → Settings → Permission Wizard, allow CuteRemote in System Settings → Privacy & Security → Screen Recording. The app restarts itself to apply.

Can't control mouse/keyboard from the browser?

Remote input needs the Accessibility permission: menu bar icon → Settings → Permission Wizard, allow CuteRemote in System Settings → Privacy & Security → Accessibility. Viewing works without it.

Forgot the access password?

On the Mac: menu bar icon → Settings → Password section, clear and set a new one.

Can multiple devices connect at once?

Yes. 3 simultaneous connections by default, adjustable up to 10 in Settings. New devices are rejected when full.

Does any data go to the cloud?

No. Video and input travel peer-to-peer, encrypted, within your local network. CuteRemote has no cloud servers and collects no data. See the Privacy Policy.
